# Visualiseurs de rapports GTFS

Pages statiques (HTML/JS, sans dépendance) pour explorer les rapports JSON produits par la chaîne GTFS de route-graph-generator :

- [rapport-collecte.html](rapport-collecte.html) : `get_all_gtfs_report.json`
- [rapport-traitement.html](rapport-traitement.html) : `processing_report.json`

Les fichiers sont chargés (bouton ou glisser-déposer) et traités localement dans le navigateur.

## Publication sur GitHub Pages

1. Pousser ce dépôt sur GitHub.
2. *Settings* → *Pages* → *Source* : `Deploy from a branch`, branche `main`, dossier `/ (root)`.
3. Le site est disponible sur `https://<utilisateur>.github.io/<dépôt>/`.

## Utilisation locale

Ouvrir `index.html` directement dans un navigateur.
